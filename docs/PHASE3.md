# 第三阶段 · 策略与回测交付说明

本阶段把「看得懂数据」升级为「能验证想法」：一份可在 Linux / Windows / Android 上原生
编译的量化核心（`core/`，纯 std、零第三方依赖），加上三端通用的回测工作台页面。

---

## 一、架构决策：为什么单独抽一个 `core/` crate

| 方案 | 问题 |
|------|------|
| 计算逻辑写在 `src-tauri` 里 | Tauri 依赖太重，任何指标改动都要等整套 GTK/WebKit 编译，迭代慢；也无法在 CI 里秒级跑测试 |
| 计算逻辑放到 FastAPI | 回测是逐 Bar 紧循环，走 HTTP 序列化开销大；且离线时回测不可用 |
| **纯 std 独立 crate（本方案）** | `cargo test` 秒级反馈；三端同一份代码；不引入任何第三方 crate，规避 Android NDK 交叉编译时的依赖地狱 |

`core` 是独立 workspace（自己声明了 `[workspace]`），因此不会被 `src-tauri` 的构建配置污染；
`src-tauri` 通过 `qbot-core = { path = "../core" }` 以路径依赖复用。

## 三、撮合规则（这部分决定回测结果可不可信）

1. **信号与成交分离**：第 `i` 根 Bar 收盘产生信号，第 `i+1` 根 Bar **开盘价**成交。
   这是最容易出错的地方——若用当日收盘信号在当日收盘成交，任何策略都会凭空多出收益。
   代码里有专门测试 `signal_executes_next_bar_not_same_bar` 锁定该行为。
2. **T+1**：当日买入当日不可卖出（`allow_t0 = false` 默认）。
3. **整手交易**：按 100 股向下取整，零头不买。
4. **费用**：买入收佣金（最低 5 元）+ 过户费；卖出再加印花税（万五）。费用会占用现金，
   因此满仓买入时引擎会**自动减一手**以容纳费用——有测试覆盖。
5. **滑点**：通过成交价体现（买入上浮、卖出下调），不重复计入 `fee`。
6. **止损 / 止盈**：盘中止损按 `low` 触发、止盈按 `high` 触发，成交价取触发价；
   若开盘已跳空越过触发价，则按开盘价成交（不虚构不存在的价格）。
7. **资金约束**：买入同时受可用现金与 `max_position_pct` 限制，绝不透支。

### 绩效口径

- 收益率一律小数表示（`0.23` = 23%）；
- 年化按 252 交易日**几何**折算，不足一年不做强行外推放大（半年的 10% 年化为 21%，不是 20%）；
- 夏普 / 索提诺无风险利率默认年化 2%；
- 最大回撤基于每日权益的历史最高点，并返回峰值/谷值日期；
- 盈亏比为无穷大时序列化为 `null`（JSON 不支持 Infinity），前端显示 `∞`。

## 四、策略清单

| ID | 名称 | 逻辑 | 适合行情 |
|----|------|------|---------|
| `dual_ma` | 双均线 | 金叉买入、死叉清仓 | 单边趋势 |
| `macd` | MACD | DIF 上穿 DEA 买入，可选仅零轴上方 | 趋势确认 |
| `kdj` | KDJ | 超卖区金叉买、超买区死叉卖 | 震荡 |
| `boll` | 布林带 | 跌破下轨买、回到中轨/触上轨卖 | 震荡回归 |
| `turtle` | 海龟交易 | 突破 N 日高买、跌破 M 日低卖 | 强趋势 |
| `grid` | 网格交易 | 每跌一格加仓、每涨一格减仓 | 区间震荡 |
| `rsi` | RSI 反转 | RSI 上穿超卖阈值买、进超买区卖 | 超跌反弹 |
| `volume_breakout` | 量价突破 | 创新高 + 放量买入，跟踪止损离场 | 放量突破 |

参数规格（范围/默认值/步长）在 Rust 侧统一定义，前端自动渲染滑块，前后端不会漂移。

## 五、参数优化

- 算法：**网格搜索**（不做贝叶斯/遗传——网格结果可复现、可解释，且纯内存计算足够快）；
- 组合数上限 500，超限直接返回明确错误，避免手机端被超大空间卡死；
- 目标函数：夏普 / 累计收益 / 卡玛 / 索提诺；
- **过拟合提示**：若最优参数正好落在搜索区间的端点上，返回警告提示扩大区间——
  这是最容易被忽略的陷阱（最优值贴边往往说明真实最优在区间之外）。

## 六、验证结果

```
$ cd core && cargo test
running 27 tests  (indicators)   ok
running 17 tests  (backtest)     ok
running 11 tests  (metrics)      ok
running  7 tests  (strategies)   ok
running  6 tests  (optimizer)    ok
test result: ok. 67 passed; 0 failed
```

```
$ npx tsc --noEmit      → 0 error
$ npx vite build        → 3647 modules, dist 生成成功
```

测试重点（不是「跑通就算」）：
- 指标对照手算值（如 EMA 种子 2→3→4、WMA 14/6、RMA 1.5→2.25→3.125）；
- 行为锁定：次日开盘成交、T+1 禁当日卖出、整手取整、最低佣金、止损跳空取开盘价、费用导致自动减手；
- 边界安全：周期大于数据量、一字板（区间为 0）、空输入、非法配置、未知策略。

## 七、已知限制

| 项 | 现状 | 后续 |
|----|------|------|
| 日线回测 | 已支持 | 分钟线需后端提供分钟 K 线（AkShare 有限速） |

| 参数优化并行 | 串行（500 组约 1~2 秒） | Android 上如需更快可加 rayon（会引入依赖，暂不引入） |
| 分红送股 | 用后复权价规避 | 若需精确现金流，需接入分红明细 |
